# Repository workflow

- Submit every change to `main` through a pull request. Never push directly to `main`, force-push it, or delete it.
- After opening or updating a PR, wait for the repository owner, `zuohuiyang`, to explicitly confirm that specific PR before merging. Requests to implement, test, commit, push, or release do not grant merge approval. Passing CI does not grant approval either.
- Do not enable auto-merge, schedule a merge, approve a PR on the owner's behalf, or use the owner's ruleset bypass to merge without that confirmation.
- Do not weaken or disable branch protection to complete a task. GitHub access through the owner's account does not replace human confirmation.
