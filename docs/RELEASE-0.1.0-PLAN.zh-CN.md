# electron-benchmarks 0.1.0 发布计划

目标日期：2026-10-31

目标：发布可安装、可直接调用、便于 AI 消费结果的首个 npm 版本。按已确认的 PRD 完成非冷启动部分，冷启动留到后续版本。

## 1. 本版范围

| 提供的命令 | 功能 |
| --- | --- |
| `startup` / `startup:warm` | 热启动速度测试 |
| `memory` | 内存测试 |
| `cpu` | CPU 测试 |

三项均支持单版本、多版本对比、发布版本号与本地构建混用、CLI 与 JSON 配置、结构化结果。

`startup:cold`、`startup:all` 和 `all` 按现有 PRD 都包含冷启动，本版暂不开放，调用时明确提示尚未支持。本版不触发系统重启或配置测试自启动。

其他平台、新测试场景、任务管理和诊断采集不纳入本次发布。

## 5. 完成标准

用户可以直接安装并调用：

```powershell
npm install --global electron-benchmarks@0.1.0
electron-benchmarks startup --electron 40.0.0
electron-benchmarks memory --electron 40.0.0
electron-benchmarks cpu --electron 40.0.0
```

三项都能生成可供 AI 读取和迁移的结果；安装、文档与实际行为一致，冷启动明确不在本版范围内。

执行顺序：实现收尾 → 自动化检查 → 安装包实测 → 文档对齐 → 发布 → 从 npm 回归验证。
